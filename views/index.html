HOW IT WORKS

Simple API endpoint

GET /api/:date?

Send a date or Unix timestamp as the optional URL parameter. Leave the parameter empty to get the current time.

DATE /api/2015-12-25
UNIX /api/1451001600000
CURRENT /api

RESPONSE FORMAT

Predictable JSON output

01

Unix Timestamp

Returns the date as the number of milliseconds since January 1, 1970.

unix: 1451001600000
02

UTC Date

Returns the same date using the standard UTC date-time format.

utc: "Fri, 25 Dec 2015..."
03

Error Handling

Invalid dates return a clear JSON error response instead of crashing the application.

error: "Invalid Date"
